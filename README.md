# COH2 VeLas Data Analytics & DPS Comparison Tool

### 💡 Project Overview
This is a high-performance **Data Visualization Interface** developed to bridge the gap between complex backend game statistics and user-centric tactical decision-making. 

### 🎯 The Problem I Solved
In the *Company of Heroes 2 VeLas* community, balance discussions are often hindered by "hidden stats" and subjective opinions. 
- **The Friction:** Players struggle to understand the actual combat efficiency (DPS) of units across different ranges.
- **The Solution:** I established a collaborative partnership with a community developer to adapt their proprietary framework, creating a customized **self-service data repository**. By integrating 100+ variables from my custom mod, I provided players with a transparent, evidence-based platform for strategic analysis.

### 📈 Key Impact
- **Enhanced Community Engagement:** Successfully reduced community friction by providing objective data metrics.
- **Data Integrity:** Ensured 100% accuracy in mapping internal engine attributes to a web-based visual dashboard.

### 🛠️ Technical Implementation
- **Logic:** Custom data mapping from game-engine attributes to HTML-based visual charts.
- **UX/UI:** Focused on high-readability and rapid data comparison for "Real-time" tactical reference.
